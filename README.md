# Orange County SLP Pay by District

A one-page website comparing pay for school-based speech-language pathologists (SLPs) across Orange County, California school districts: starting and top pay with SLP stipends, the maximum with every stipend, pay per work day, how each district pays SLPs (own schedule vs. teacher schedule plus a stipend), caseload caps and duty days.

Compiled in October 2026 from district certificated salary schedules and union contracts. Not an official district or union document; confirm figures with each district's human resources office.

## Files

- `index.html` - the page
- `data.js` - the data the page reads
- `oc_slp_pay.csv` - the same data as a spreadsheet

## Updating the numbers

Edit the district's row in `data.js` (and `oc_slp_pay.csv`), then commit. GitHub Pages republishes automatically.
